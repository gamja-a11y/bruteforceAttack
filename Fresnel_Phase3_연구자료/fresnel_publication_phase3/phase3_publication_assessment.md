# Phase 3 독립 홀드아웃 평가

24개 물리 조건 × 두 잔차. Phase 2 파일과 선택기 해시는 holdout_manifest.json에 있다. A는 원본 탐색, B는 사전 고정 선택, C는 64차·512비트 고정이다. 목표는 상대폭 1%, 절대폭 1e-5를 동시에 충족하는 것이다.

A — 목표 달성 30/48 (62.5%), 검증 구간 보유 48/48, 후보 205개, 총 126.01초, 최고 관측 작업자 메모리 45.7 MiB.

B — 목표 달성 30/48 (62.5%), 검증 구간 보유 48/48, 후보 59개, 총 86.12초, 최고 관측 작업자 메모리 50.3 MiB.

C — 목표 달성 30/48 (62.5%), 검증 구간 보유 48/48, 후보 48개, 총 112.81초, 최고 관측 작업자 메모리 51.3 MiB.

양쪽 모두 목표를 달성한 30건의 누적 wall-clock은 A 56.63초, B 41.77초다. 개별 A/B 시간비 중앙값은 1.50다. 방법 순서를 순환한 단일 직렬 실행이며 CPU·컴퓨터 간 속도 우위로 일반화할 수 없다.

독립 검증 통과는 고정된 Theorem 1과 Arb를 신뢰 기반으로 둔 해당 입력 구간의 수치 인증이다. 두 폭 목표의 통과 여부는 이진 유리수로 별도 판정했다. 사례별로 세 방법의 모든 승인 구간이 공통점을 갖는지도 확인했다.

논문에서 제시할 수 있는 기여는 동일한 연속 원판 복소장 RMS에 대해 초타원 모멘트로 두 물리 모델 잔차의 양측 구간을 계산하고, 사전 고정한 선택기를 미사용 조건에서 검증한 실험이다. 최초성이나 임의 개구의 보장은 이번 실험으로 입증되지 않는다.

투고 전에는 새 극단 조건에서 더 큰 예산(특히 96·128차)을 사전 고정한 두 번째 홀드아웃, 동일 목표 성공 사례의 반복·교차 하드웨어 시간 측정, 독립 구현 또는 고정밀 직접 적분 대조가 우선이다. 성공률은 정해진 격자의 기술통계이며 무작위 모집단 추정치가 아니다.

재현 시 Phase 2의 Python 3.14.7 및 python-flint 0.9.0 환경에서 별도 사본을 사용한다. 원래 디렉터리 구조와 holdout_manifest.json을 보존하고 빈 runs 경로에서 python -B experiment.py, 이어서 python -B analyze.py를 실행한다. Windows Job Object의 프로세스별 commit 상한은 512 MiB, 보고 메모리는 작업자 peak working set이다. 시간은 검색 전체이며 종료 결과 JSON 기록과 후처리는 제외한다.
