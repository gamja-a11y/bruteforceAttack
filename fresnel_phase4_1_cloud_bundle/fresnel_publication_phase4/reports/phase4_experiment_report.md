# Phase 4 홀드아웃 및 비용 평가

90초·프로세스당 commit 768 MiB, 공통 수치 백엔드. 홀드아웃은 동시 작업자 최대 4개, 대표 반복은 다른 실험과 겹치지 않는 직렬 냉시작이다. wall-clock은 프로세스 시작, 선택용 contour, 재발급 contour, 발급, 독립 검증 및 파일 기록을 포함한다. 표의 합은 작업별 경과시간의 합이다. 과거 Phase 3 30초 기록은 이 표에 합치지 않았다.

개발 정책 비교에서 A는 동결된 기존 정책과 늘어난 시간 예산, B는 ρ=2 고차수, Cfixedbits는 가변 ρ에 1024비트 고정, C는 가변 ρ·차수·정밀도 결합 방식이다. 개발 단계에서는 이 네 가지를 A/B/C/D로 부른다. 홀드아웃 C는 개발 D다. 개발 측정은 다른 개발 작업과 동시 진행해 성능 일반화에 사용하지 않는다.
